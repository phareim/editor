# 🎯 Awesome Terminal Editor

A playful and powerful terminal text editor written in JavaScript! 🚀

## ✨ Features

- 📝 Full-featured terminal text editing
- ⌨️ **Ctrl+S** (⌘S) to save files
- 🚪 **Ctrl+X** (⌘X) to exit editor
- 📂 **Ctrl+O** (⌘O) to open files
- 📄 **Ctrl+N** (⌘N) for new files
- 💾 Smart save detection with unsaved changes warnings
- 🎨 Beautiful colored interface with status bar
- 🖱️ Mouse support for navigation
- 🎭 Fun and friendly user experience

## 🚀 Installation

### Global Installation (Recommended)
Install globally to use the `awesome-editor` or `aed` command anywhere:

```bash
npm install -g .
```

### Local Installation
```bash
npm install
```

## 📖 Usage

### Global Usage (after global install)
```bash
# Start the editor
awesome-editor

# Or use the short alias
aed

# Open a specific file
awesome-editor myfile.txt
aed myfile.txt
```

### Local Usage
```bash
# Start the editor
npm start
# or
node editor.js

# Open a specific file
node editor.js myfile.txt
```

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| **Ctrl+S** (⌘S) | Save current file |
| **Ctrl+X** (⌘X) | Exit editor |
| **Ctrl+O** (⌘O) | Open file |
| **Ctrl+N** (⌘N) | New file |
| **Ctrl+C** or **ESC** | Exit editor |
